# 随译 v0.1.2

有道翻译改用官网游客文本翻译。升级后可以直接翻译，并可在「服务设置 → 翻译」里测试连接。

## 下载与安装

| 文件 | 适用设备 |
| --- | --- |
| `SuiTranslate_0.1.2_aarch64.dmg` | Apple M 系列 Mac |
| `SuiTranslate_0.1.2_x64-setup.exe` | Windows x64 安装版 |
| `SuiTranslate_0.1.2_x64-portable.zip` | Windows x64 免安装版 |
| `SHA256SUMS.txt` | 三个下载文件的 SHA-256 校验值 |

Mac 用户打开 DMG 后将 SuiTranslate 拖入「应用程序」。Windows 安装版含 WebView2 引导程序。使用免安装版时，请安装 WebView2 Runtime 并完整解压 ZIP，再打开 `SuiTranslate.exe`。[WebView2 下载](https://developer.microsoft.com/en-us/microsoft-edge/webview2/)

升级沿用应用标识 `com.lochungyin.sui.translate`、本地设置和历史记录。首次启动会从当前配置中移除默认和自定义有道实例的旧应用 ID 与密钥，同时保留实例名称、顺序和启用状态。

## 更新

- 有道网页游客翻译无需账号、应用 ID 或 API Key。界面移除了凭据输入和申请入口，保留「测试连接」。
- 有道可用语种跟随官网游客版，返回文本译文。原智云接入特有的语种和结构化词典释义随旧接入停用。
- 有道请求遇到限流、登录要求、网页验证或网络错误时显示相应提示。Google 翻译与应用代理继续沿用原有设置。
- 清理设置、关于页和插件选择弹窗中的旧帮助入口，并更新随译的外部调用示例。

## 验证与限制

- 前端 13 项和 Rust 4 项测试通过。已校验 DMG、NSIS 安装包和免安装 ZIP 的完整性。直接从 v0.1.2 DMG 运行的应用成功清除隔离配置中的旧凭据，并将 `Hello, world!` 译为「你好，世界！」。
- 发布前的 macOS arm64 验证中，无凭据的有道实例在工作台、输入浮窗和「测试连接」均返回真实译文。隔离配置也验证了默认和自定义有道实例的旧凭据迁移。[验证记录](https://github.com/lochungyin/translate/blob/v0.1.2/docs/VALIDATION.md)
- macOS 安装包使用本地 ad-hoc 签名，未提交 Apple 公证。升级后如需使用划词翻译，请在「系统设置 → 隐私与安全性 → 辅助功能」重新授权当前的 SuiTranslate。
- Windows x64 安装包和免安装包来自交叉构建，未签名。Windows 实机启动、在线翻译、WPS 划词、截图和系统 OCR 待验证。Intel Mac 和 Linux 未实测。
