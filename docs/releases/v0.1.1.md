# 随译 v0.1.1

发布日期：2026-10-14（Asia/Shanghai）。

## 下载

[GitHub Release](https://github.com/lochungyin/translate/releases/tag/v0.1.1) 提供：

| 文件 | 适用设备 |
| --- | --- |
| `SuiTranslate_0.1.1_aarch64.dmg` | Mac M 系列芯片，arm64 |
| `SuiTranslate_0.1.1_x64-setup.exe` | Intel / AMD 64 位 Windows，安装版 |
| `SuiTranslate_0.1.1_x64-portable.zip` | Intel / AMD 64 位 Windows，免安装版 |
| `SHA256SUMS.txt` | 下载文件的 SHA-256 校验值 |

Windows 安装包包含 WebView2 引导程序；免安装版需预装 WebView2 Runtime。Mac 打开 DMG 后将 SuiTranslate 拖入「应用程序」。应用标识和数据目录保持 `com.lochungyin.sui.translate`，沿用现有设置与历史。

## 更新

- 改善工作台、服务列表、历史记录和翻译浮窗的缩放布局、滚动及长文本显示。
- 原文与译文输入框根据文字、字体大小和窗口宽度调整高度。
- 划词未获信任或选区为空时打开翻译浮窗并显示原因，支持继续手动输入。
- 浮窗请求使用带序号的快照，避免首次打开时丢失内容或错误提示；窗口事件限定到当前浮窗。
- 快捷键设置明确显示停用状态，并提供恢复默认快捷键。
- macOS 打包时完整签署应用包，修复旧包资源签名不完整的问题。
- Windows 与 macOS 版本号统一，手动 GitHub Actions 构建流程覆盖两个目标。

## 验证与限制

本次执行前端 12 项回归测试、原生网络 3 项测试、Rust 格式检查和两端 Release 构建。安装包检查及校验值分别记录在 [Windows 检查结果](../windows-build-results.json) 与 [Mac 检查结果](../macos-build-results.json)。

此前在本机原生应用中验证过 Google 和已配置的有道翻译；签名修复及辅助功能授权重新绑定后，用户也确认划词快捷键显示浮窗与译文，详见 [专项验证](../SHORTCUTS_VALIDATION.md)。这些结果不代替新版本在每个设备上的全功能验收。

- Windows 版本通过交叉编译与安装包检查，尚未在实际 Windows 设备上验证启动、WPS 划词、截图或 OCR。
- Mac 解锁后已完成同一正式包的工作台、固定浮窗、重复提交、权限提示与版本显示复测；Google 和已配置的有道均显示真实译文，详见 [补充复测记录](v0.1.1-macos-validation.md)。新包尚未获得辅助功能信任，实体键盘跨应用划词仍需重新授权后验收。
- Mac 使用本地 ad-hoc 签名，未使用 Apple Developer ID 签名或公证；Windows 未进行代码签名。系统可能显示来源验证提示。
- Mac 更新后辅助功能或屏幕录制权限可能需要重新绑定当前安装的应用并重启；不能保证本地签名跨版本沿用授权。
- 有道需要用户自己的应用 ID / 密钥。Google 免费网页协议受网络、服务限流和接口变化影响。
